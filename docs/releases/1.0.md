# Velvet 1.0

Velvet is a native YouTube client for macOS. It uses much less memory than YouTube in a browser. This is the first public release.

**Browse**

- Home, Subscriptions, Search, History, Watch Later, Playlists, Liked videos and channels.
- Shorts, live streams and live chat.
- Account notifications and optional macOS notifications for new uploads.

**Watch**

- mpv playback with hardware decoding. Quality up to 4K and HDR.
- Resume, captions, chapters, theater mode and loop.
- SponsorBlock, DeArrow and Return YouTube Dislike.
- Queue, playlists, series detection and Picture in Picture.
- Comments, likes, subscriptions and Save to playlist.

**Light on memory**

- Approximately 360 MB for a 1440p video. Safari uses approximately 1.4 GB for the same video.
- No analytics and no telemetry. Your cookies stay on your Mac.

**Requirements**

- macOS 15 or later.
- Apple silicon or Intel. The Intel build is untested: it is built and checked, but nobody has run it on an Intel Mac yet. If you try it, please report what happens.

Velvet updates itself. It also updates yt-dlp and the JavaScript runtime.
